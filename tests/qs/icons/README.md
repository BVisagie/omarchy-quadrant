# Documentation app icons

These fixed assets keep native documentation captures independent of the
host's installed applications and icon theme. They identify illustrative
processes, not running applications on the machine producing the capture.

- `t3code-nightly.png`: unmodified T3 Code Nightly application icon from the
  installed `t3code-nightly-bin` package. Upstream:
  [pingdotgg/t3code](https://github.com/pingdotgg/t3code), with its MIT license
  included as `LICENSE.t3code`.
- `brave-origin.png`: unmodified Brave Origin application icon from the
  installed `brave-origin-bin` package. Upstream:
  [brave/brave-browser](https://github.com/brave/brave-browser), with its MPL
  2.0 license included as `LICENSE.brave`.
- `application-x-executable.svg`: an original generic window illustration
  under this repository's MIT license.

Application names and logos remain the property of their respective owners.
